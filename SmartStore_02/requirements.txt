# ==================== 依赖冲突解决说明 ====================
#
# 1. NumPy 版本冲突：
#    - TensorFlow 2.15.0 要求: numpy>=1.23.5,<2.0.0
#    - PyTorch 2.1.0 要求: numpy>=1.21.0
#    - OpenCV 4.8.1 要求: numpy>=1.21.2
#    - 解决方案: 使用 numpy==1.24.3（所有库的交集）
#
# 2. Protobuf 版本冲突：
#    - TensorFlow 2.15.0 要求: protobuf>=3.20.3,<5.0.0
#    - 解决方案: 使用 protobuf==4.23.4
#
# 3. PyTorch vs TensorFlow：
#    - 两者可以共存，但建议分别使用
#    - PyTorch 用于 YOLO 和其他 CV 任务
#    - TensorFlow 专用于 DeepFace 人脸识别
#
# 4. CUDA 版本要求：
#    - PyTorch 2.1.0 + CUDA 11.8
#    - TensorFlow 2.15.0 + CUDA 11.8 (通过 tensorflow[and-cuda])
#    - 确保系统已安装 CUDA 11.8 和 cuDNN 8.6+
#
# 5. 已移除的冲突库：
#    - face-recognition (需要 dlib，难以安装)
#    - dlib (需要 C++ 编译器)
#
# ==================== 安装顺序（重要！）====================
#
# 步骤 1: 安装 CUDA 和 cuDNN
#   - CUDA 11.8: https://developer.nvidia.com/cuda-11-8-0-download-archive
#   - cuDNN 8.6+: https://developer.nvidia.com/cudnn
#
# 步骤 2: 创建虚拟环境
#   python -m venv venv
#   venv\Scripts\activate
#
# 步骤 3: 升级 pip
#   python -m pip install --upgrade pip
#
# 步骤 4: 安装 PyTorch (CUDA 11.8)
#   pip install torch==2.1.0 torchvision==0.16.0 --index-url https://download.pytorch.org/whl/cu118
#
# 步骤 5: 安装其他依赖
#   pip install -r requirements.txt
#
# 步骤 6: 验证安装
#   python -c "import torch; print(f'PyTorch: {torch.__version__}, CUDA: {torch.cuda.is_available()}')"
#   python -c "import tensorflow as tf; print(f'TensorFlow: {tf.__version__}, GPU: {tf.config.list_physical_devices(\"GPU\")}')"
#   python -c "from deepface import DeepFace; print('DeepFace OK')"
#

# ==================== 常见问题 ====================
#
# Q1: numpy 版本冲突？
# A: 严格使用 numpy==1.24.3，不要升级
#
# Q2: TensorFlow 找不到 CUDA？
# A: 检查环境变量 PATH 是否包含 CUDA 路径
#
# Q3: PyTorch 找不到 CUDA？
# A: 确认安装的是 cu118 版本，不是 CPU 版本
#
# Q4: DeepFace 下载模型失败？
# A: 手动下载模型到 ~/.deepface/weights/
#
# Q5: 内存不足？
# A: 降低 batch_size，或使用更小的模型（如 OpenFace）
