# 用户注册功能说明

## 功能概述

在 SmartStore 主页的"顾客检测"区域新增了**主动注册入口**，用户可以点击"立即注册"按钮进行注册并录入人脸信息。

---

## 功能特点

### ✅ 两步注册流程

#### 步骤 1: 录入人脸
- 打开注册模态框后自动启动摄像头
- 用户正对摄像头，确保光线充足
- 点击"📷 拍摄人脸"按钮
- 系统自动检测人脸并提取特征
- 显示拍摄的照片预览
- 支持"🔄 重新拍摄"功能

#### 步骤 2: 填写信息
- 姓名（必填）
- 手机号（可选）
- 邮箱（可选）
- 点击"✓ 完成注册"提交

## 技术实现

### 前端部分

#### HTML 结构
- `index.html` 新增：
  - 注册按钮（`#register-btn`）
  - 注册模态框（`#registration-modal`）
  - 人脸拍摄区域（`#register-video`, `#register-canvas`）
  - 注册表单（`#registration-form`）

#### CSS 样式
- `style.css` 新增：
  - `.btn-register` - 注册按钮样式
  - `.modal` - 模态框遮罩层
  - `.modal-content` - 模态框内容区
  - `.face-capture-container` - 人脸拍摄容器
  - `.form-group` - 表单样式
  - 响应式设计支持

#### JavaScript 功能
- `main.js` 新增函数：
  - `openRegistrationModal()` - 打开注册模态框
  - `closeRegistrationModal()` - 关闭模态框
  - `startRegisterCamera()` - 启动注册摄像头
  - `stopRegisterCamera()` - 停止摄像头
  - `captureFacePhoto()` - 拍摄人脸照片
  - `showCapturedFace()` - 显示拍摄预览
  - `recaptureFace()` - 重新拍摄
  - `submitRegistration()` - 提交注册
  - `resetRegistrationForm()` - 重置表单

### 后端 API

#### POST /api/v1/customer/detect
用于人脸检测和特征提取

**请求**:
```json
{
  "image": "<base64-encoded-image>"
}
```

**响应（新用户）**:
```json
{
  "success": true,
  "message": "检测到新顾客",
  "data": {
    "face_count": 1,
    "recognized": false,
    "faces": [
      {
        "encoding": [0.123, 0.234, ...],
        "confidence": 0.95
      }
    ]
  }
}
```

#### POST /api/v1/customer/register
用于注册新用户

**请求**:
```json
{
  "name": "张三",
  "phone": "13800000000",
  "email": "zhangsan@example.com",
  "face_encoding": [0.123, 0.234, ...]
}
```

**响应**:
```json
{
  "success": true,
  "message": "注册成功",
  "data": {
    "id": 42,
    "user": { ... }
  }
}
```

## 用户流程

```
1. 用户访问 SmartStore 主页
   ↓
2. 点击"👤 立即注册"按钮
   ↓
3. 注册模态框弹出，摄像头自动启动
   ↓
4. 用户正对摄像头
   ↓
5. 点击"📷 拍摄人脸"
   ↓
6. 系统检测人脸并提取特征（调用 /customer/detect API）
   ↓
7. 若检测成功，显示照片预览，自动进入步骤 2
   ↓
8. 用户填写姓名、手机号、邮箱
   ↓
9. 点击"✓ 完成注册"
   ↓
10. 提交到后端（调用 /customer/register API）
    ↓
11. 注册成功，显示欢迎消息
    ↓
12. 模态框关闭，摄像头停止
```

## 安全与验证

### 前端验证
- ✅ 姓名必填
- ✅ 必须先录入人脸
- ✅ 检测是否已注册（防止重复）
- ✅ 手机号、邮箱格式验证（HTML5）

### 后端验证
- ✅ 姓名不能为空
- ✅ 人脸特征不能为空
- ✅ 手机号唯一性检查
- ✅ 邮箱唯一性检查
- ✅ 人脸质量检查（置信度 > 0.9）

---

## 错误处理

### 摄像头错误
- 无法访问摄像头 → 提示检查权限
- 摄像头未准备好 → 提示稍后再试

### 人脸检测错误
- 未检测到人脸 → 提示正对摄像头
- 人脸质量不佳 → 提示改善光线
- 检测到已注册用户 → 提示无需重复注册

### 注册错误
- 姓名为空 → 提示输入姓名
- 手机号已存在 → 提示手机号已注册
- 邮箱已存在 → 提示邮箱已注册
- 网络错误 → 提示网络异常

## 常见问题

### Q: 点击注册按钮后摄像头没反应？
A: 检查浏览器是否已授予摄像头权限

### Q: 人脸检测一直失败？
A: 确保光线充足，正对摄像头，距离适中（30-50cm）

### Q: 注册后无法识别？
A: 检查 `face_encoding` 是否正确存储，阈值是否合理（10.0）

### Q: 重复注册同一个人会怎样？
A: 系统会检测到已注册，提示"无需重复注册"
